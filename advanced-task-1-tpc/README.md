# РСХД. Задание 1. Специализация СУБД

1. Получите от преподавателя несколько SQL-запросов из наборов:
   [TPC-H, TPC-DS](https://www.tpc.org/tpc_documents_current_versions/current_specifications5.asp).

2. Согласуйте с преподавателем СУБД для специализации. Например,
   [PostgreSQL](https://www.postgresql.org/),
   [YDB](https://ydb.tech/ru/).

3. Разверните выбранную СУБД на Linux.

4. Наполните СУБД данными при помощи генератора из бенчмарка.

5. Выполните запрос, зафиксируйте
   результат,
   метрики производительность,
   план выполнения.

6. Итеративно изменяйте настройки СУБД, а также создавайте и редактируйте
   схемные объекты (индексы, layout данных) с целью повышения
   производительности. После каждой итерации фиксируйте результаты по
   инструкции в предыдущем пункте.

7. Проанализируйте полученные результаты.
