# РСХД. Задание 2. MapReduce

1. Получите от преподавателя несколько SQL-запросов из наборов:
   [TPC-H, TPC-DS](https://www.tpc.org/tpc_documents_current_versions/current_specifications5.asp).

2. Согласуйте с преподавателем MapReduce систему. Например,
   [YTsaurus](https://ytsaurus.tech/ru),
   [Hadoop](https://hadoop.apache.org/).

3. Разверните последнюю стабильную версию выбранной MapReduce системы на Linux.

4. Наполните MapReduce систему данными при помощи генератора из бенчмарка.

5. Реализуйте каждый SQL-запрос на императивном языке программирования,
   используя соответсвующий SDK.

6. Выполните разработанные графы вычислений при помощи SDK.

7. Выполните запросы при помощи SQL-движка. Например,
   [YQL](https://ytsaurus.tech/docs/en/yql/),
   [Apache Hive](https://hive.apache.org/).

8. При необходимости, сконфигурируйте систему или измените реализацию
   на императивном языке программирования так, чтобы получить
   удовлетворительную производительность.

9. Сравните результаты, производительность и планы выполнения реализации
   на императивном языке программирования и SQL.
